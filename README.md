# clinic-voice-notes

以語音輸入協助醫療人員整理、編輯與確認病歷草稿。

## 專案目標

將口述內容轉為文字，再整理成結構化病歷草稿，減少重複輸入的負擔。
所有輸出都需要由醫療人員核對、修正與確認後，才能納入正式病歷。

## 預計使用流程

1. 醫療人員錄音或輸入語音。
2. 將語音轉錄為可編輯文字。
3. 整理成 SOAP 或其他病歷格式的草稿。
4. 醫療人員檢視內容、補充資訊並修正錯誤。
5. 確認後匯出，供後續病歷作業使用。

## 初期功能規劃

- 錄音與語音輸入
- 語音轉文字
- 病歷草稿整理與編輯
- 草稿匯出

## 目前狀態

目前僅建立專案骨架與說明文件，尚未實作上述功能；技術選型與開發方式待確認。

## 隱私與使用界線

- 請勿在此公開儲存庫、Issue 或提交紀錄中放入真實病人資料、錄音、病歷或憑證。
- 開發與展示僅使用虛構、無法識別個人的測試資料。
- 本專案定位為病歷草稿輔助工具，不提供自動診斷，也不取代醫療人員的專業判斷。
- 導入實際臨床場景前，須另行評估資料保護、存取控制、保存政策與適用法規；目前不代表已取得任何法遵認證。
